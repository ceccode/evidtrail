# @evidtrail/core

Git collection, two-axis AI provenance (mode × evidence), and versioned schemas for evidtrail. Reads `AI-Mode:`, `Assisted-by:`, `AI-Session:` and co-author trailers; a commit with no signal stays `unknown`.

## Features

- Git commit collection with diff statistics
- AI-assisted commit detection using configurable heuristics
- Commit stream normalization and schema validation
- File system utilities for JSON I/O

## Usage

```typescript
import { collectCommits, createLogger } from '@evidtrail/core';

const commitStream = await collectCommits({
  repoPath: '/path/to/repo',
  since: '90d',
  aiPatterns: ['custom-ai-pattern'],
  logger: createLogger(true),
});
```

## AI Detection

Signals, from strongest to weakest:

- **Declared** — `AI-Mode: <none|autocomplete|assisted|agent>` states the autonomy level; `Assisted-by: <tool>` declares AI involvement with the level left `unknown`; the attribution manifest declares commits retroactively.
- **Inferred** — a `Co-authored-by:` that names an AI tool or its domain (a co-author with "bot" in the name is not enough), `AI: true` / `X-AI: true`, an `[ai]` tag, or a sentence such as "generated by Claude".
- **Session** — `AI-Session: <agent>/<id>` is read into `commit.session`; it links a commit to its agent session and is not evidence by itself.

`createProvenanceTagger` combines these with automated-commit detection (merges, known bots) and the manifest, so every command reaches the same decision for the same commit.
